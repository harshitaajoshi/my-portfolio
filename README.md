# My Portfolio

A personal portfolio website built for **CS 3365 - Software Engineering (Fall 2026), Assignment 1**.

The purpose of this project is to practice a realistic Git and GitHub development
workflow: working in feature branches, committing incrementally, merging into a
stable `main` branch, and deploying the result with GitHub Pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
